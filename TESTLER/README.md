# Tests

[Türkçe](README_TR.md)

This folder contains the tests supporting the claims in Final Form. Each test has its own folder with its code, a `TEST.md` description in English and `TEST_TR.md` in Turkish. The description states what the test checks, how it works, why it matters and the single-line command to run it.

Commands are run from the repository root. GCC is enough for C tests, and Python 3 for Python tests.

I ran the tests again on 25 October 2026. The results are in the [Verification section of Final Form](../md/FINAL_FORM/CTCPU_FINAL_FORM.md#14-verification), each with a link to its test. The four FAILS in the journal claims are not errors, they are results showing that those claims did not hold.

The tests under `HUNTER/` are organised by parts of the Hunter project. Under `NIHAI_EK/`, there are two verification programs written separately for Final Form.
